# StoryNest Design System

## Colors (Design Tokens)
- **Primary (Forest):** #003631 (Drenched background, high authority)
- **Accent (Gold/Cream):** #FFEDA8 (Highlights, CTAs)
- **Surface:** #FFFFFF (Card backgrounds in Light Mode)
- **Muted:** #7db8b2 (Secondary text, inactive states)

## Typography
- **Heading:** Oswald (Geometric, strong, authoritative)
- **Body:** Urbanist (Highly legible, modern sans-serif)
- **Logo:** Dealva (Sophisticated serif)

## Spacing & Rhythm
- Base Unit: 4px
- Standard Padding: 24px (L), 16px (M), 12px (S)

## Elevations
- Standard Card: Radius 16px, Shadow Offset 0/4, Blur 20, Spread 0, Opacity 0.1 (Primary Tinted)
